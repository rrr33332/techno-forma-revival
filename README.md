# Nova Post Perfection

Доделай проект вот дангные. https://github.com/romapokrov226-cmd/seo-relaunch-modernization . 


Проведи повний аудит усього сайту та виправ усі знайдені проблеми. Не обмежуйся лише окремими багами — переглянь логіку, UX, адаптивність, роботу API, продуктивність та якість коду.

1. Доставка Новою Поштою

Повністю перероби процес вибору доставки так, щоб він був максимально простим і логічним.

Нова логіка

Поточна логіка незручна.

Замість:

Область → Місто → Тип доставки → Точка

зроби:

Місто → Відділення Нової Пошти

Користувач повинен лише знайти своє місто.

Після вибору міста автоматично завантажуються ВСІ доступні відділення цього міста.

Не потрібно окремо вибирати:

поштомат;

самовивіз;

тип доставки;

інші зайві кроки.

Просто показуй список усіх відділень, які повертає API Нової Пошти для вибраного міста.

Якщо API повертає звичайні відділення та поштомати, можна показувати їх разом в одному списку, але без окремого вибору типу доставки. Користувач просто обирає потрібну точку зі списку.

2. Перевірити весь довідник Нової Пошти

Повністю перевір роботу API.

Особливо перевір:

чи завантажуються всі області України;

чому відсутня Харківська область;

чи немає інших відсутніх областей;

чи всі міста доступні;

чи всі міста можна знайти через пошук;

чи не губляться міста через фільтрацію або кеш.

Перевір як великі міста, так і маленькі населені пункти.

3. Виправити пошук

Пошук має бути швидким.

Під час введення:

не повинно бути зависань;

не повинно бути старих результатів;

не повинно бути дублювань;

не повинно бути порожніх списків без причини.

Якщо приходить новий запит, старі відповіді API не повинні його перезаписувати.

4. Якщо у місті немає відділень

Не показувати порожній список.

Краще показати повідомлення:

"Для цього населеного пункту відділення Нової Пошти не знайдено."

5. Повна адаптивність сайту

Повністю перевір сайт на телефонах.

Зараз є багато проблем:

картинки обрізаються;

деякі блоки виходять за межі екрана;

текст іноді накладається;

кнопки занадто маленькі;

окремі сторінки виглядають зламаними;

деякі модальні вікна не поміщаються;

іноді неможливо переглянути повністю картинку;

окремі секції не масштабуються правильно.

Перевір сайт на:

320 px

360 px

375 px

390 px

414 px

430 px

планшетах

великих телефонах

Android

iPhone

Жоден елемент не повинен виходити за межі екрана.

Жодна картинка не повинна обрізатися.

Усі кнопки повинні бути зручними для натискання пальцем.

Всі модальні вікна повинні відкриватися повністю без обрізання.

Усі сторінки повинні однаково добре працювати як на телефоні, так і на комп'ютері.

6. Загальна перевірка

Перевір увесь сайт на:

JavaScript помилки;

помилки React;

помилки в консолі;

неправильні API-запити;

дублікати компонентів;

зайві ререндери;

витоки пам'яті;

проблеми продуктивності;

повільне завантаження;

биті зображення;

биті посилання.

7. UX

Зроби сайт максимально сучасним.

Користувач повинен виконувати будь-яку дію за мінімальну кількість кліків.

Прибери все, що лише ускладнює оформлення замовлення.

8. Фінальна перевірка

Після всіх змін самостійно протестуй весь сайт.

Перевір:

ПК;

планшет;

телефон.

Упевнися, що всі сторінки відкриваються без помилок, доставка Новою Поштою працює коректно, усі картинки відображаються повністю, а сайт виглядає професійно та однаково добре на будь-якому пристрої.

"Не обмежуйся мінімальними змінами. Якщо бачиш, що логіку або структуру компонента краще переробити повністю — перероби її. Пріоритет — зручність користувача, стабільність і сучасний UX."
